Can *Top Down Tank Controls* be fun?

import { YouTube } from 'astro-embed';

<YouTube id="https://www.youtube.com/watch?v=Rt_upW4CFQg" />

In my humble opinion, yes!

This controls prototype is a proof of concept that tries to answer this question.
The idea was *What if the original Resident Evil (1996) was a top-down shooter?*

This prototype makes heavy use of Unity's *Animation Rigging* package (head direction, aiming, right hand on holster, etc.) and the Animator's root motion.
